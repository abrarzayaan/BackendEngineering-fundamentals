এখন একজন user তোমার website-এ গিয়ে একটি medicine search করল।

কিন্তু একটা প্রশ্ন: User-এর browser কীভাবে তোমার backend-এর সঙ্গে যোগাযোগ করে???
Browser কীভাবে জানে backend কোথায় আছে? কীভাবে data পাঠায়? কীভাবে backend সেই request গ্রহণ করে? 
কীভাবে backend database থেকে data নিয়ে আবার browser-এ পাঠায়?

এই পুরো communication-এর পেছনে কাজ করে Computer Networking...!!!

Computer Network কী?
সহজ ভাষায়:
```Computer Network হলো একাধিক independent computing device-এর মধ্যে একটি communication system, 
যার মাধ্যমে তারা নির্দিষ্ট rules বা protocols অনুসরণ করে data আদান-প্রদান এবং resources share করতে পারে।```

এখানে কয়েকটি গুরুত্বপূর্ণ বিষয় আছে।
Computing Device = Computer, Server, Mobile, Router
Connection = Device-গুলোর মধ্যে যোগাযোগের ব্যবস্থা
Data Exchange = তথ্য আদান-প্রদান
Protocol = Communication-এর নির্দিষ্ট নিয়ম
Resource Sharing = File, Printer, Database, Services share করা

একটি গুরুত্বপূর্ণ বিষয়: Network communication-এর জন্য সবসময় physical cable প্রয়োজন হয় না। 
Wired এবং wireless—দুইভাবেই network তৈরি হতে পারে।


Why do we need Networking?
Networking না থাকলে প্রতিটি computer অনেকটা বিচ্ছিন্নভাবে কাজ করত।
Networking আমাদের প্রধানত পাঁচটি সুবিধা দেয়:

A. Communication : একটি device অন্য device-এ message বা data পাঠাতে পারে।
B. Resource Sharing: একাধিক computer একই printer, file storage বা server ব্যবহার করতে পারে।
C. Centralized Data Management: একটি centralized database-এ অনেক application বা user access করতে পারে।
D. Distributed Computing: একটি বড় application-এর কাজ একাধিক server বা service-এর মধ্যে ভাগ করে দেওয়া যায়।
E. Scalability: User বাড়লে একাধিক server যুক্ত করে system-এর capacity বাড়ানো যায়।

Backend engineering-এর ক্ষেত্রে শেষের তিনটি বিশেষভাবে গুরুত্বপূর্ণ।

Network-এর সবচেয়ে গুরুত্বপূর্ণ Architecture: Client-Server Model

এখানে দুটি প্রধান participant রয়েছে:

- Web Browser

Server: যে system client-এর request গ্রহণ করে এবং প্রয়োজনীয় service বা resource প্রদান করে।

উদাহরণ:
- Web Server
- Application Server
- Database Server
- File Server


একটি বাস্তব উদাহরণ
ধরো, একজন user OneMed-এ login করতে চায়।

Communication flow:

1. Client
Browser / Mobile App
Login credentials পাঠায়

        |
        V

2. Backend Server

        |
        V

3. Database Server
User information retrieve

        ^

মনে রাখবে, এটি একটি simplified logical flow। বাস্তবে DNS lookup, TCP connection, TLS handshake, HTTP request/response-এর মতো 
আরও অনেক ধাপ থাকতে পারে। এগুলো আমরা পরবর্তী lessons-এ বিস্তারিত শিখব।


Client এবং Server কি আলাদা ধরনের Computer?
না। এটি খুবই গুরুত্বপূর্ণ।

Client এবং Server মূলত কোনো hardware-এর নাম নয়; এগুলো একটি communication-এর role।একটি সাধারণ laptop একই সময়ে:
- অন্য server থেকে webpage চাইলে Client।
- নিজের computer থেকে কোনো অন্য device-কে file serve করলে Server।
অর্থাৎ, একটি device একই সময়ে Client এবং Server—দুই ভূমিকাতেই থাকতে পারে।
